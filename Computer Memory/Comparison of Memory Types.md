- [[DRAM]]: 
	- Very high density - Cheap data cache in computers
	- Must be periodically refreshed 
	- [[Volatility of Memory|Volatile]]: Not used for long term storage

- [[SRAM]]:
	- Fastest type of memory
	- Low density $\rightarrow$ more expensive
	- generally used in small amounts (L2 Cache) or expensive servers


- EEPROM:
	- Slow/complex to write - not used for fast cache
	- [[Volatility of Memory|non-volatile]]: best choice for program memory

- [[ROM]]:
	- Hardware coded data - Rarely used except for boot-up code

- Register (Flip Flop):
	- functionally similar to [[SRAM]] but less dense and more expensive
	- reserved for data manipulation applications

- **PROM**: Programmable Read Only Memory
	- programmable by user - using special program tools/modes
	- Read Read only Memory [[ROM]] - During normal use 
	- [[Volatility of Memory|non-volatile]]

- *Read operation*: like any [[ROM]] - address bits select output bit combinations
- *Write operation*: typically requires high voltage (~15V) control inputs to set data, stores charge to floating gate to set Hi or Low
![[PROM - Floating gate.png|485]]

- *Erase Option*:
	- EPROM: Erasable PROM: uses UV light to reset all bits
	- EEPROM: Electrically erasable PROM: erase with control voltage

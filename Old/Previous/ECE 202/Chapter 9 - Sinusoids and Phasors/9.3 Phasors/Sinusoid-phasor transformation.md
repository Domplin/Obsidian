| Time Domain Representation      | Phasor Domain Representation |
| ------------------------------- | ---------------------------- |
| $V_{m} \cos(\omega t+\phi)$<br> | $V_{m}\angle\phi$            |
| $V_{m}\sin(\omega t+\omega)$    | $V_{m}\angle\phi-90^\circ$   |
| $I_{m}\cos(\omega t+\theta)$    | $I_{m}\angle\theta$          |
| $I_{m}\sin(\omega t+\theta)$    | $I_{m}\angle\theta-90^\circ$ |
an italic letter, *z* is used to represent complex numbers but bold letters, **V** to represent phasors, because phasors are vectorlike

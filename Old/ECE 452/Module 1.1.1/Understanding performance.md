Suppose you want to design a game console to play games with excellent performance

What factors impact the performance of the system?

- **Algorithm**
	- Determines the number of operations executed
- **Programing Language, compiler, ISA**
	- Determine number of machine instructions executed per operation
- **Processor and memory system**
	- Determine how fast instructions are executed
- **I/O system (including OS)**
	- Determines how fast I/O operations are executed
- **Underlying technology (e.g., photonics, NVRAM)**
	- Sets limits on achievable performance at higher levels

Computer architects need to be aware of how each HW and SW layer impacts latency/throughput, power/energy, reliability, security, cost, etc.

The **unit step function** $u(t)$ is 0 for negative values of $t$ and $1$ for positive values of $t$. 
![[Pasted image 20240226180308.png]]
The unit step function is undefined at $t=0$, where it changes abruptly from 0 to 1 

The **unit step function** is used to represent abrupt changes in voltage or current, like the changes that occur in the circuit of control systems and digital computers.

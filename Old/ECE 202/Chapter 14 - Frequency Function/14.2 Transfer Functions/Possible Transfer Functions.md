Assuming zero initial conditions. Since the input and output can either be voltage or current at any place in the circuit, there are four possible transfer functions. 

| $H(\omega) = Voltage Gain = \frac{V_{o}(\omega)}{V_{i}(\omega)}$             |
| ---------------------------------------------------------------------------- |
| $H(\omega) = Current Gain = \frac{I_{o}(\omega)}{I_{i}(\omega)}$             |
| $H(\omega)=Transfer Impedance = \frac{V_{o}(\omega)}{I_{i}(\omega)}$         |
| $H(\omega) = Transfer admittance = \frac{I_{o}(\omega)}{V_{i}(\omega)}$ <br> |
*The subscripts $i$ and $o$ represent the input and output values, respectively*

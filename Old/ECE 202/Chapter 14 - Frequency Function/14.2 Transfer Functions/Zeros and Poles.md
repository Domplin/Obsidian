A **Zero**, as a *root* of the numerator polynomial is a value that results in a zero value of the function.

The Zeros are usually represented as $j\omega=z_{1},z_{2},\dots$ 

A **Pole** as a *root* of the denominator polynomial, is a value for which the function is infinite.

The Poles are usually represented as $j\omega=p_{1},p_{2},\dots$ 

A zero might also be regarded as $s=j\omega$ that makes $H(s)$ zero, and a pole as the value of $s=j\omega$ that makes $H(s)$ infinite.

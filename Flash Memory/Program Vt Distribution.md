$n=$ # of injected electrons for a given program pulse to obtain $\Delta V_{T}$
$$
\Delta V_{T}=\frac{qn}{C_{box}}
$$
Assuming that the electron-injection process is ruled by a *Poisson Statistics*, we can write the following:
$$
\sigma_{\Delta V_{T}}= \frac{q}{C_{box}}\sqrt{ \bar{n} } = \sqrt{ \left( \frac{q}{c_{box}}\bar{\Delta V_{T}} \right) }
$$


*Gate area shrinks (so is $C_{box}$) with technology scaling making $\sigma_{\Delta V_{T}}$ higher*
